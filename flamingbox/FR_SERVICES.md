# Flamme — services français intégrés

## Services grand public prioritaires
- Recherche : Qwant
- Mail principal : laposte.net
- Mail alternatif / agenda / cloud léger : Mailo
- Cloud / fichiers : Twake / Cozy
- Cartes : cartes.gouv.fr (IGN)

## Services publics / État
- LaSuite : portail souverain de la DINUM
- Docs : éditeur collaboratif de l’État
- Fichiers / Visio / Tchap / Grist : via LaSuite selon éligibilité ProConnect
- CryptPad LaSuite : instance sécurisée pour les agents éligibles

## Pourquoi pas CaraMail comme mail principal ?
La marque CaraMail actuelle est liée à GMX/United Internet, groupe allemand. Elle ne correspond donc pas à la règle « service français » de Flamme.

## Principe produit
Flamme n’héberge pas ni ne réplique les données des fournisseurs. Le navigateur fournit un accès intégré et cohérent à leurs services officiels. Les comptes restent gérés par chaque fournisseur.
